## 🎸 2. String Harmonics Solution

### 📐 The Problem
A guitar string is **64 cm** long and has a fundamental frequency (one antinode) of **330 Hz**. 

* **Length ($L$):** $64 \text{ cm} = 0.64 \text{ m}$
* **Frequency ($f$):** $330 \text{ Hz}$
* **Mode:** Fundamental (1 antinode)

---

### 💡 Physics Principle
For a string fixed at both ends, the fundamental frequency occurs when the length of the string is equal to half of one wavelength:
$$L = \frac{\lambda}{2} \implies \lambda = 2L$$

Once the wavelength is found, the wave speed ($v$) is calculated using:
$$v = f \cdot \lambda$$

---

### 🛠️ Step-by-Step Solution

#### **Step 1: Calculate the Wavelength ($\lambda$)**
Since the string vibrates with one antinode (the fundamental mode):
$$\lambda = 2 \cdot 0.64 \text{ m}$$
$$\lambda = 1.28 \text{ m}$$



#### **Step 2: Calculate the Wave Speed ($v$)**
Using the wave equation:
$$v = 330 \text{ Hz} \cdot 1.28 \text{ m}$$
$$v = 422.4 \text{ m/s}$$

---

### 📊 Summary Result

| Parameter | Value |
| :--- | :--- |
| **String Length** | $0.64 \text{ m}$ |
| **Wavelength** | $1.28 \text{ m}$ |
| **Frequency** | $330 \text{ Hz}$ |
| **Wave Speed** | **$422.4 \text{ m/s}$** |

**Conclusion:** The wave travels along the guitar string at a speed of **$422.4 \text{ m/s}$**.
