# 8. Work of a Variable Force

**Force:** $F(x) = -kx$

**Solution:**
* **Equation of Motion:** $m\ddot{x} + kx = 0$. Solution: $x(t) = A\cos(\omega t + \phi)$.
* **Work Done:** $W = \int_{0}^{x_0} -kx \, dx = \mathbf{-\frac{1}{2}kx_0^2}$.
* **Potential Energy:** Defined as $\Delta U = -W$, so $U(x) = \mathbf{\frac{1}{2}kx^2}$.
* **Verification:** $F = -\frac{dU}{dx} = -\frac{d}{dx}(\frac{1}{2}kx^2) = -kx$. (Verified).
