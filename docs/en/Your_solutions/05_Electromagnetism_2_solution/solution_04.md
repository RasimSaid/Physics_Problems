# 🧲 4. Magnetic Torque

---

## 📌 Problem

🔹 Length = 0.10 m  
🔹 Width = 0.05 m  
🔹 Current (I) = 2 A  
🔹 Magnetic field (B) = 0.3 T  
🔹 Field is parallel to the plane of the loop  

🎯 Find the magnetic torque

---

## 🧠 Formula

$$
\tau = N I A B \sin\theta
$$

---

## 📐 Step 1: Area of the loop

```
A = l × w
A = 0.10 × 0.05
A = 0.005 m²
```

---

## 📐 Step 2: Angle condition

🧭 Magnetic field is parallel to the loop plane

👉 Therefore:

```
θ = 90°
sinθ = 1
```

---

## ⚙️ Step 3: Torque calculation

```
τ = (1)(2)(0.005)(0.3)(1)
τ = 0.003 N·m
```

---

## ✅ Final Answer

$$
\boxed{\tau = 3.0 \times 10^{-3} \, N \cdot m}
$$

---

## 🧲 Visual Intuition

```
          B-field direction
      → → → → → → → → → → →

        ┌───────────────┐
        │               │
        │   LOOP        │   I (current)
        │               │
        └───────────────┘

🧭 Field is parallel to loop
⚡ Current loop experiences torque
```

---

## 💡 Key Insight

- Field || plane ⇒ torque exists  
- θ = 90° ⇒ maximum torque  
- Loop behaves like a magnetic dipole
